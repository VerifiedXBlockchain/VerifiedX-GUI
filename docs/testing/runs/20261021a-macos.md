### TC-SEND-016 · Invalid recipient address (step 2)

A real mainnet address on testnet is refused with `Invalid Address.` rather than the 9.0 message `This address belongs to another network. Anything sent there could never be spent.`. `isValidRbxAddress` (`lib/utils/validation.dart:40`) requires an `x` first character on testnet and runs before `isOtherNetworksVfxAddress`, so the other-network message cannot be reached from the send form with a real other-network address. The send is still refused. Issue #306 (P2, both platforms by code).
