## Defects found (none caused by #72)

- **#364 (P1, both wallets):** the send and NFT-transfer address fields drop `-`, so names with a hyphen (valid under the grammar rule) can't be sent to by name. Pre-existing input filter; the wallets' own create dialogs also drop `-`.
- **#365 (P1, macOS):** NFT transfer terminated, the testnet beacon answers 403 to the asset upload. Infrastructure; check the mainnet beacon before relying on NFT transfers there.
- **#366 (P1, web):** first NFT transfer after a mint fails "Could not create beacon upload request."; a retry works.
- **#367 (P2, web):** a token transfer two blocks after the mint fails "Invalid transaction data." with no reason; a retry works.
- **#368 (P2, macOS):** Privacy dashboard trusts a stored `zfx_` the node doesn't hold after a data-folder reset.
